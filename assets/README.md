# Branding image

`indra_mirror_leech_banner.png` is the optional welcome banner for this customized build.

To use it in Telegram:
1. Send this PNG to your bot in a private chat or a private channel.
2. Copy the Telegram photo `file_id` using your preferred bot/API utility.
3. Set `START_IMAGE = "<photo_file_id>"` in your private `config.py`.
4. Restart the bot.

You may also use a direct image URL. Do not commit private configuration or tokens.
